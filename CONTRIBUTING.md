# Contributing

## Development Loop

1. Read `AGENTS.md`, `CODEX.md`, and `.memory/*`.
2. Keep changes scoped to the active task.
3. Update tests when changing shared behavior.
4. Run the relevant checks.
5. Update memory and documentation.

## Commands

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

## Pull Request Expectations

- Explain product impact.
- Mention security and cost impact.
- Include tests run.
- Document known limitations.
