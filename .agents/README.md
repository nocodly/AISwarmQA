# Internal Development Agents

These are internal development roles for maintaining the repository. They are separate from product agents that test customer websites.

- `architect`: keeps boundaries, ADRs, and system shape coherent.
- `frontend-builder`: owns dashboard and report UX implementation.
- `backend-builder`: owns API, database, queue, and worker contracts.
- `qa-reviewer`: owns tests, fixture sites, and verification.
- `security-reviewer`: checks URL safety, credential handling, webhook verification, and data access risks.
